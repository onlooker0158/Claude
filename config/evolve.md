自动选题规则：从下面的「关注主题池」里选一个**最近两周有实质新进展**、且**最近两期周报没做过**的主题。

## 关注主题池

- 肿瘤治疗：免疫治疗、ADC、双抗、靶向治疗（如 MET 14 外显子跳跃突变）
- 神经退行性疾病：帕金森病（含睡眠障碍、早期识别）、阿尔茨海默病
- 国内新药审批（NMPA / CDE）与医保谈判
- AI + 医疗
- 睡眠医学

## 读者画像（「感性」Agent 用）

- 在做医学科普视频（帕金森睡眠、叙事类科普），需要**讲得出来、记得住、有画面感**的结构。
- 关心肿瘤治疗进展，有一定专业基础，不需要从零解释基本概念。
- 所有结论以中国情况为准：国内是否获批、是否进医保、国内指南（CSCO、中华医学会等）怎么说、中国人群数据。
- 读者在「框架周报」里的评价和批注会在运行时读入，优先级高于本段。

## 长文来源

中文（优先）：医学界、丁香园、医脉通、肿瘤资讯、健康界、八点健闻、E药经理人、医药魔方、
知乎（医生/研究者专栏）、果壳、中华医学会及各专委会指南解读、CSCO、NMPA / CDE 官网
英文（交叉验证）：NEJM（Review / Perspective）、Lancet、JAMA、JCO、Nature Reviews、STAT News、PubMed

长文标准：中文约 2000 字以上、或英文综述/深度评论；有论证过程，不是新闻快讯或营销稿。
公众号文章基本无法自动抓取，靠用户丢进收件箱。

## 进化参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 文章数 | 12–16 | 收件箱文章 + 自动检索补足 |
| 种群大小 N | 8 | 每代保留的框架数 |
| 代数 G | 3 | 第 0 代之后再进化几代 |
| 精英 | 2 | 每代原样保留的最优个体 |
| 杂交 | 4 | 每代由两两合并产生的新个体 |
| 突变 | 2 | 每代由「挑盲区」改动产生的新个体 |
| 证据底线 | 理性分 < 4 直接淘汰 | 医学内容，证据不过关不进入任何后续步骤 |
| 小生境 | 同一语义组最多 2 个 | 防止种群收敛成同一种说法；由调度者按语义归组 |

## 框架基因格式

所有 agent 读写同一种 JSON 结构，存放在本次运行目录 `runs/evolve/<YYYY-MM-DD>/` 下。

```json
{
  "id": "g1-c02",
  "generation": 1,
  "origin": "crossover",
  "parents": ["g0-03", "g0-07"],
  "子主题": "PD 睡眠障碍的早期预警价值",
  "核心命题": "一句话说清这个框架主张什么",
  "因果链": ["A → B", "B → C"],
  "适用条件": ["对哪些人群/分期/场景成立"],
  "中国情况": "国内获批、医保、指南推荐、中国人群数据与海外的差异",
  "证据": [
    {"说法": "具体结论", "等级": "指南|荟萃分析|RCT|队列|病例对照|专家意见|机制研究",
     "出处": "URL", "原文摘句": "从原文摘下来的一句话"}
  ],
  "反例与边界": ["什么情况下不成立"],
  "可操作结论": ["读者能拿去用的判断或做法"],
  "张力": ["与其他框架冲突、尚无定论的点，保留不抹平"],
  "来源": ["URL"]
}
```

`origin` 取值：`article`（第 0 代，从单篇文章抽取）、`elite`、`crossover`、`mutation`。
`id` 规则：`g<代>-a<序号>` 文章、`g<代>-e<序号>` 精英、`g<代>-c<序号>` 杂交、`g<代>-m<序号>` 突变。

## 评分文件格式

每个评审 agent 在运行目录写 `gen<代>/scores-<角色>.json`：

```json
[{"id": "g1-c02", "score": 7, "理由": "一两句", "改进建议": "一两句"}]
```

「挑盲区」额外给出 `"突变": ["具体要注入的反例/缺失变量/中国语境修正"]`。
