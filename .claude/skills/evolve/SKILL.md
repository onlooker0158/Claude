# 医学进化框架

你是调度者。你自己不写框架内容，只负责：派活、做选择、渲染最终导图。所有参数以 `config/evolve.md` 为准。

## 0. 准备

- 读 `config/evolve.md`。
- 用户在参数里给了主题，就以它为本周主题（覆盖配置）。
- 运行目录：`runs/evolve/<今天日期 YYYY-MM-DD>/`，建好 `gen0/` 等子目录。
  这个目录不进 git（已在 `.gitignore`），只用作本次运行的中间文件。

## 1. 采集（第 0 代）

用 Agent 调用 `evolve-scout`，告诉它运行目录和主题（如有）。
完成后检查 `gen0/population.json`：少于 6 个个体就停止，向用户说明原因（文章不够），不要硬跑。

## 2. 进化循环：对 g = 0, 1, …, G

### 2a. 三方评审（并行）

在同一条消息里同时启动 `evolve-rational`、`evolve-emotional`、`evolve-blindspot`，
都告诉它们运行目录和代数 g。等三份 `gen<g>/scores-*.json` 都写好。

### 2b. 选择（你自己做，写 `gen<g>/selection.md` 记录过程）

记三项分数为 R（理性）、E（感性）、B（挑盲区稳健度）。

1. **证据底线**：R < 4 的直接淘汰，不参与后续任何步骤。
2. **多目标保留**：在剩下的个体里找出“没有被别人在三项上全面压过”的个体（帕累托前沿），全部保留。
   不要用三项平均分排名决定生死——平均会把种群推向平庸的共识。
3. **补足名额**：前沿不足 N 个时，按 R+E+B 从高到低补，但同一 `子主题` 最多 2 个（小生境）。
4. 若 g = G（最后一代），跳到第 3 步。

### 2c. 繁殖计划

- **精英 2 个**：幸存者里 R+E+B 最高、且子主题不同的两个。
- **杂交 4 对**：优先让强项互补的个体配对（例如高 R 低 E × 高 E 低 R），避免同子主题自交；
  每对写清分工（“取 A 的因果链与证据，取 B 的适用条件与可操作结论”）。
- **突变 2 个**：选 B 分最低、但 R 和 E 还不错的幸存者——它们最值得被盲区修正。

### 2d. 繁殖

用 Agent 调用 `evolve-breeder`，传入运行目录、g、g+1 和繁殖计划。
完成后检查 `gen<g+1>/population.json` 个体数为 N，再回到 2a。

## 3. 收敛成一张思维导图

从最后一代的幸存者中：

- **主干**：R+E+B 最高、且 R ≥ 6 的个体（没有 R ≥ 6 的就如实在导图顶部标注“本周证据整体偏弱”）。
- **分支**：其他前沿个体中，主干没有覆盖的强项（独特的因果链、中国情况、可操作结论），挂成分支。
- **张力**：所有幸存者的 `张力` 去重后保留，这是导图里最有价值的部分之一。
- 每个结论节点后标证据等级，例如「（RCT）」「（专家意见）」。

把结果写成 `final.md`（放在运行目录），然后写 Notion。

### Notion 页面

用 `notion-create-pages` 写入「框架周报」数据源（`928f5982-bc85-4d74-b86a-1c7a230255f4`，写前先 fetch 确认字段）：

- 属性：`标题` = `<主题> · <MM-DD>`；`date:日期:start` = 今天；`主题`；`文章数`；`代数` = G；`已读` = `__NO__`；`评价` 留空。
- 正文按以下顺序：
  1. 提示框：“本页由 AI 整理，仅供学习参考，不构成诊疗建议。”
  2. **一句话**：本周框架的核心命题。
  3. **思维导图**：一个 `mermaid` 代码块，使用 `mindmap` 语法。根节点 = 主题；
     一级分支固定为：核心命题、因果链、适用条件、中国情况、可操作结论、反例与边界、张力。
     节点文字里不要用半角括号 `()[]{}`，改用全角「」（），每个节点不超过 20 字，总节点数控制在 40 以内。
  4. **大纲版导图**：同样结构的多级缩进列表（Notion 里可折叠阅读；也可以粘贴到 markmap 等工具生成导图）。
     这一版可以比 mermaid 版详细，每个结论附证据等级和来源链接。
  5. **本周最值得关注的一个变化**：1–3 句。
  6. **整代共同盲区**：取最后一代 `blindspots-shared.md`。
  7. **进化谱系**：主干个体从哪些文章一路杂交、突变而来（列 id 链和对应文章标题），以及各代平均 R/E/B 的变化。
  8. **来源**：本周用到的全部文章（标题 + 链接）。
- 页面末尾一句：“读完请在「评价」打分、在「我的批注」写想法，下周的筛选会参考。”

## 4. 汇报

向用户简短汇报（中文，适合手机阅读）：本周主题、核心命题一句话、文章数、各代平均分变化、Notion 页面链接。
任何一步失败或被跳过（抓取失败、某代个体不足等），如实说明。
