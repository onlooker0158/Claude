# 资讯简报

用户手动触发了一次资讯整理。

1. 从参数中解析：
   - 领域：`科技` / `AI` → 科技/AI；`财经` / `投资` → 财经/投资；`行业` / `学术` / `医药` → 行业/学术；未指定则三个领域全部整理。
   - 时间范围：如“今天”“最近三天”“最近一周”；未指定则用 `config/sources.md` 中的默认值（最近 24 小时）。
   - 其他词视为额外关注的主题关键词。

2. 用 Agent 工具调用 `news-curator` 子 agent，把解析后的领域、时间范围、额外关键词写进 prompt。
   三个领域都要整理时，可并行启动三个 `news-curator`，每个只负责一个领域，以加快速度。

3. 汇总子 agent 的返回结果，用中文向用户简要报告：每个领域的重点条目、写入条数，以及 Notion 链接
   https://app.notion.com/p/6de0e4386d054b598d52e71774678117
