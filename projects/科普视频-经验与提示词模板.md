# 科普视频：流程、经验和提示词模板

来自《叙事：这个宇宙的第一性原理》那一支（2026-10-10，黑板粉笔画，7 分 20 秒，用 huashu-art-motion skill 做）。

## 一、流程（实际走过的 9 步）

| 步 | 做什么 | 你要参与吗 | 耗时参考 |
|---|---|---|---|
| 1 | 读原文，写旁白文稿（压缩、保留原文措辞），列出删了什么 | 想严格忠实就在这一步看文稿 | 几分钟 |
| 2 | 出三个画风方向的样帧，构图不同 | **要选一个** | 几分钟 |
| 3 | 定配音：云语音男声/女声、已有录音、或只上字幕 | **要选一个** | — |
| 4 | 逐句合成配音，生成词级时间轴和字幕 | 否 | 1–2 分钟 |
| 5 | 写镜头表（每镜一个具体的物在做一件事），过 lint | 否 | — |
| 6 | 写画面代码，抽帧检查 | 否 | 最长的一步 |
| 7 | 全片渲染（4 段并行） | 否 | 7 分钟的片约 25 分钟 |
| 8 | 门禁检查 + 派一个没参与制作的 agent 独立审片 | 否 | 5–10 分钟 |
| 9 | 按审片意见修订、重渲、交付 | 看成片 | 每轮约 30 分钟 |

## 二、经验

**内容**
- 文稿是骨架。删掉的东西事先说清楚；这次审片才发现两处删减让意思变绝对了（"你不能说事实不重要"的保留语、线索的五种形态）。要求严格忠实，就让我先给文稿、你确认后再配音——改文稿要重配音、重排时间轴，越晚改越贵。
- 时长估算：云希男声加速 6% 约 4.6 字/秒，2000 字 ≈ 7 分 20 秒。想要 3 分钟左右，文稿压到 800 字上下。
- 原文里中文语境敏感的例子，我会先删掉并告诉你；要保留就在提示词里写明。

**画面**
- 全片一个具体例子贯穿最管用：这次是开头的"门 → 馒头 → 饱"，讲顺序、因果、舞台时都飞回去用它，观众有抓手。
- 一种画风、一套色板到底；不画人脸、不给物加脸。没有生图能力时，"只用物讲故事"比代码画小人好得多。
- 粉笔字和图要整体让开底部字幕带，这次是统一缩 10%、上移，比逐镜调省事。
- 黑板这种深色、稀疏的画风，门禁的"快动作"指标天然偏低（同样幅度的推拉测出来变化小），要每镜在口播节点上做一次快推/横移，板面加旧板书残影这类纹理。亮底风格（纸本、海报）更容易过。

**工程**
- 一次全片渲染约 25 分钟，每轮修订都要重渲一次。所以先抽帧把问题改干净，再渲全片。
- 独立审片很值：这次挑出 7 处必须改（字压字幕、舞台那一镜太短、星球上的馒头太小）。
- 发送上限 30MB：7 分钟 1080p 约 60MB，会另压一版 720p（约 26MB）发给你，原片留在项目目录。
- 云语音在这个环境要用 `/root/.ccr/ca-bundle.crt` 做证书，否则连不上。

## 三、怎么给我提示词

**最简版**（其余按默认：横屏 1080p、三方向给你挑、男声、烧录字幕、压缩到原文主干）：

```
用 huashu-art-motion 把这个文件做成科普视频：<附件或路径>
```

**完整版**（每一项都可以省略，省略就用括号里的默认）：

```
用 huashu-art-motion 把 <附件/路径> 做成科普视频。
- 时长：约 X 分钟（默认：按原文主干压缩，不设上限）
- 忠实度：逐段保留 / 压缩但保留原文措辞 / 自由改写（默认：压缩但保留措辞）
- 必须保留：<哪些例子、哪些原话、小诗、数据>
- 可以删：<哪些>；敏感内容：保留 / 删掉并告诉我（默认：删掉并告诉我）
- 先给我看文稿再配音：是 / 否（默认：否）
- 画风：黑板粉笔 / 纸本插画 / 剪纸海报 / 其他 / 先给三个方向（默认：先给三个方向）
- 配音：云语音男声 / 女声 / 我的录音 <路径> / 不配音只上字幕（默认：先问我）
- 画幅：横屏 1920×1080 / 竖屏 1080×1920（默认：横屏）
- 受众：<例如：没有物理背景的成年人>
- 交付：1080p 原片 + 720p 预览 + 字幕 srt（默认）
```

**例子**：

```
用 huashu-art-motion 把附件做成 3 分钟的竖屏科普视频，给抖音用。
压缩但保留原文措辞，小诗和三个作用必须保留，敏感例子删掉并告诉我。
先给我看文稿再配音。画风沿用上次的黑板粉笔，配音用云希男声。
```

**沿用这次的设置**：说"和《叙事》那支一样的做法"，我会复用 `projects/叙事科普/代码工程/` 里的黑板引擎、道具库和配音脚本，只换文稿和镜头表，比从零做快很多。
