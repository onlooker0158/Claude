# 板板：账号形象人设

## 一句话

一块会讲故事的小黑板。脸是用粉笔画在自己板面上的，所以表情随时能擦掉重画——就像它最常说的那句话：**故事是可以改写的**。

## 它从哪来

《叙事：这个宇宙的第一性原理》那支片子整个画在一块大黑板上。板板就是那块黑板本身：片头的「门 → 馒头 → 饱」一直写在它板面左下角，片尾那句「至于写什么，由我选择」是它的座右铭。

## 设定

| 项 | 内容 |
|---|---|
| 名字 | 板板 |
| 身份 | 账号的讲解员，读书笔记的「黑板」 |
| 性格 | 好奇、爱追问「为什么」；讲到兴头上会把脸擦了画个图；不装权威，说错了就擦掉重写 |
| 口头禅 | 「来，我在板上给你画一下。」「擦掉，重写。」「住于故事，不囚于故事。」 |
| 声音 | 旁白用的云希男声（片子里那个声音就是它） |
| 招牌动作 | 举粉笔（要讲了）、拿板擦擦脸（换个角度想）、指向旁边（看这里） |

## 造型规范（保持一致）

- **结构**：木框黑板＋三脚画架当腿＋两条木头胳膊（白色手套）＋橙红色鞋。
- **颜色**：板面 `#23302B`，粉笔白 `#F1EFE6`，粉笔黄 `#F4D35E`，橙红 `#E87D5A`（鞋、强调），木框 `#B98A5A` / 暗面 `#8E6440`，手套 `#F4ECDA`，板擦 `#2F5D62`。
- **脸**：只用粉笔线画在板面上（白色）。眼睛是杏仁形、上眼睑压住瞳孔上沿、目光对焦；眉毛是平缓的弧，常有一边微挑；嘴是单边上扬的浅笑；不画鼻子。强调符号（？！灯泡、因→果）用黄或橙红粉笔。
- **神态**：聪明、笃定、有点得意，不是呆萌——不用圆瞪的大眼、咧到底的大嘴。
- **固定细节**：木框四角铜钉、板槽里一截粉笔和一块蓝绿色板擦、板面左下角的小故事链（讲故事表情时放大）。
- **不要做**：给木框长眼睛、把脸画到框外、换成别的颜色的板面、加腮红、圆瞪眼、对眼。
